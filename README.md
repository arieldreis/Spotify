# 🎵 Spotify Clone  

Clone do **Spotify** desenvolvido com **React**, focando em interface moderna e interatividade.  
Este projeto serve como prática de **React, componentes, props e hooks**.  

---

## 📌 Funcionalidades
- ✅ Barra de navegação e playlists  
- ✅ Listagem de músicas e artistas  
- ✅ Player funcional (reprodução local ou dummy)  
- ✅ Componentização com **React**  
- ✅ Hooks: `useState`, `useEffect`  

---

## 🛠 Tecnologias
- **React 18+**  
- **JavaScript (ES6+)**  
- **CSS / Styled Components**  
- **VS Code** (IDE usada)   

---

## 🚀 Como executar
```bash
# Clone o repositório
git clone https://github.com/arieldreis/Spotify.git

# Entre na pasta
cd Spotify

# Instale as dependências
npm install

# Rode o projeto
npm run dev
